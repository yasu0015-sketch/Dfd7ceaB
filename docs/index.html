差枚・G数の推移 -

店舗全体の日別実績。0を基準に、お客様側がプラスだった日（青）とお客様側がマイナス＝店側がプラスだった日（赤）で塗り分けています。

曜日・日付ごとの傾向 -

曜日別・暦日（1〜31日）別の平均差枚。旧イベント日とされる7のつく日・1日・11日・21日・30日の傾向を見るのにも使えます。母数が少ない日は参考程度にご覧ください。

月またぎ比較（同じ日付の差枚） -

横軸を「その月の何日目か」に揃え、月ごとの折れ線を重ねて表示しています。チップをクリックすると月の表示・非表示を切り替えられます。

台番号×日付 差枚マトリクス -

機種を選ぶと、その機種に属する台番号ごとに日別の差枚を一覧表示します。セルの色が濃いほど差枚の絶対値が大きいことを示します（青＝お客様側プラス／赤＝店側プラス、他のグラフと同じ配色）。台番号は集計期間中に一度でもその機種として記録された台のみを列に表示しており、日によって設置機種が変わっている場合はデータが無い日が「—」になります。

台番号別 勝率 -

上の「台番号×日付マトリクス」で指定した集計期間の中で、選んだ機種の台番号ごとに「差枚がプラスだった日」の割合を集計します。差枚0の日は勝ちに含めません。稼働日数が少ない台は偶然の影響が大きいので、母数と合わせてご覧ください。列見出しをクリックすると並べ替えられます。

機種別サマリー -

「台番号×日付マトリクス」で指定した集計期間について、機種ごとの平均G数と勝率を一覧にします。勝率は「その機種のどれかの台が、ある日に差枚プラスだった」割合を、延べ台日（台数×稼働日数）を母数として計算しています。差枚0の日は勝ちに含めません。延べ台日が少ない機種は偶然の影響が大きいので、母数と合わせてご覧ください。列見出しをクリックすると並べ替えられます。

全台データ -

対象日の全台の台番号・機種・差枚・G数・出率。列見出しをクリックすると並び替え、検索欄・フィルターで絞り込めます。
